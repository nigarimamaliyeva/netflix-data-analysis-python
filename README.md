# Netflix Data Analysis (Python)

Internship project analyzing a Netflix content dataset using Python, pandas, matplotlib, seaborn and Plotly.

## Tasks
- **Task 1 – Data Cleaning:** Handled hidden missing values, removed duplicates, standardized ratings, split the `duration` column, and exported a cleaned dataset.
- **Task 2 – Content Type Analysis:** Analyzed the Movie vs TV Show split and how it changed over time (2010–2021).
- **Task 3 – Country-Wise Analysis:** Identified top content-producing countries and compared content types across them.
- **Task 5 – Rating & Genre Analysis:** Grouped ratings into audience bands (Kids/Teens/Adults) and analyzed the most common genres, including an interactive Plotly chart.

## Tools
Python, pandas, matplotlib, seaborn, plotly, Jupyter Notebook

## Files
- `Dataset.csv` — original dataset
- `Dataset_cleaned.csv` — cleaned dataset (output of Task 1)
- `task1_cleaning.ipynb`, `task2_content_analysis.ipynb`, `task3_country_analysis.ipynb`, `task5_rating_genre_analysis.ipynb` — notebooks for each task
